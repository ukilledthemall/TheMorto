# The Morto

A 2D survival horror game made in Unity. Survive three nights in an isolated house while a skull-faced creature searches for you.

Use cameras to track him outside, a flashlight to see in the darkness, and hiding places to escape. The flashlight raises his attention, and both it and the cameras have limited battery power.

## Controls

- **Mouse + F:** Aim and use flashlight
- **A / D:** Move between rooms
- **Space:** Open/close cameras
- **1–3:** Select camera
- **L:** Play camera speaker
- **H:** Hide/leave cover
- **P / Esc:** Pause

## Run

Open the project in Unity 6.6, open the `TheMorto` scene, and press Play. Use the Game tab with a 16:9 aspect ratio.
